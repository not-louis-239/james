# James

*Just A Modular Element Structurer*

**Version**: 0.1.0

I hope things work, but perhaps they might also just break. I don't know, I'm not a professional programmer. I just made this for fun, or rather, because I got tired of making the same widget code OVER AND OVER AGAIN for GUIs. So *James* is a library that contains various classes for common widget types with some primitive draw functions, while still allowing custom draw functions to be plugged in. 

Use it if you want, I don't care. It's a UI library that's made to work with Pygame.

## Dependencies

Intended for use with Pygame if used as part of a larger (Pygame) project.
